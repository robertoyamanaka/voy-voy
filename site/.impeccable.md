## Design Context

### Users
Developers who use Claude Code (AI-agent builders, indie hackers, engineers) arriving from X, LinkedIn, GitHub or
Hacker News. They give it ten seconds: what is it, does it work, how do I install it.

### Brand Personality
Cheeky, quick, arcade. An 8-bit carrier pigeon that takes your coding agent's calls. "voy, voy" is Spanish for
"coming, coming!". The logo is VOY² (VoyVoy = Voy squared).

### Aesthetic Direction
Structure after tamagui.dev: pixel wordmark centered in the nav, left-aligned hero with the mascot, an install
command box, a code/transcript panel on the right, a two-column "featuring" checklist. Squarish type (Chakra Petch
display, Hanken Grotesk body, Kode Mono for terminals). Light and dark, following the system, with a toggle.
Two accents with a job each: Taiko-drum red = the talker (voice), LiveKit-cyan blue = the reasoner (Claude Code).
Anti-references: SaaS gradients, glassmorphism, identical icon-card grids.

### Design Principles
1. Show the call, not adjectives: the transcript is the hero.
2. Color means something: red talks, blue thinks. Everything else is neutral.
3. Pixel art is the personality; keep the rest of the UI quiet and precise.
4. Honest by design: always say it's an AI, label examples as examples.
